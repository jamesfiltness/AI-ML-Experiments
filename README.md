## Projects

### [Llama 2 Intent Classifier](./llama2-intent-classifier/README.md)
Fine-tuned Llama 2 7B using QLoRA to classify water utility customer service messages into 15 intent categories. Trained on RunPod, adapters stored on HuggingFace Hub, deployed as a serverless API on Modal.
